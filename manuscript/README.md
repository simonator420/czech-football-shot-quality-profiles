# Applied Sciences manuscript package

This directory contains the submission-ready manuscript in editable DOCX and
rendered PDF form, together with the five numbered PNG figures.

The package uses the final out-of-fold xG run reported by the reproducibility
tables: xG per match `r = 0.751`, goals minus xG per match `r = 0.452`,
chance-creation axis `r = 0.628`, and finishing axis `r = 0.552` for the
first-half versus second-half analysis.

The PDF was rendered from the DOCX after removing the section-level
right-to-left flag. All tables therefore display in left-to-right column order.

Both data-availability references use the stable Zenodo concept DOI
[`10.5281/zenodo.22540653`](https://doi.org/10.5281/zenodo.22540653), which
resolves to the latest archived version of this repository.
